收回價分佈 · 相對期指張數

牛熊證街貨係咩

街貨 = 發行商已況出、市場仍持有、未被收回的牛／熊證數量。唔係期權 OI。

  • 牛證：看好。收回價低過現價。跌穿就收回。
  • 熊證：看淡。收回價高過現價。升穿就收回。
  • 街貨升 → 發行商對冲（牛證約買期指；熊證約賣期指）。

為何用「相對期指張數」

期指張數 ≈ 街貨份數 ÷ 換股比率 ÷ 50

50 = HSI 期貨乘數。同一區間可以有多個比率，所以用約當張數。

點樣用分佈圖

  • 現價線之上 = 熊證收回價；之下 = 牛證收回價。
  • 近價重貨區：價到就容易有收回潮 + 對冲平倉。
  • 近收回 ±1,000 點牛熊比比全日總比更敏感。
  • 期權頁仍係 HKEX options OI；本頁係 CBBC 街貨，數字唔可對調。
